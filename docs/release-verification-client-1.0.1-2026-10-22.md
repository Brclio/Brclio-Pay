# 2026-10-22 自签客户端发布核验

服务版本 1.2.1，客户端版本 1.0.1。下载入口：[pay.bornforthis.cn/clients](https://pay.bornforthis.cn/clients)；正式安装文件与审计元数据：[client-v1.0.1](https://github.com/Brclio/Brclio-Pay/releases/tag/client-v1.0.1)。

## 签名和首次安装

Mac 两种架构使用长期保留的 Brclio 自签证书，没有 Apple Developer ID 或 Apple 公证。DMG 中提供安装助手：先验证应用身份、代码签名、证书固定摘要及逐文件签名清单，再由用户输入确认短语，将应用安装到 `~/Applications/Brclio Pay.app`。助手只移除这一个已验证副本的下载隔离标记，不使用 sudo，不添加系统信任证书，不关闭全局 Gatekeeper。旧 `/Applications` 副本继续保留；退出旧客户端后打开新路径。助手被拦截时，下载页提供通过终端执行这个已下载助手的步骤。

Windows 主程序、NSIS 卸载程序和外层安装程序均使用同一个长期保留的 RSA 3072 自签代码签名证书。公开 CER 和说明文件受独立 RSA 安装元数据保护；下载页展示固定证书 SHA-256，说明核对安装程序、主动导入当前用户信任、验签和撤销信任的方法。客户端不静默添加用户信任。私钥/PFX 不进入发布文件。

自签证书不能获得 Apple 公证、微软公共根证书信任或 SmartScreen 声誉，不能承诺首次运行没有系统确认。保留现有 RSA 更新验签公钥和 Android 正式签名证书，1.0.0 客户端继续使用原更新清单 schema 发现新版。
